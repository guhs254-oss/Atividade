# 💙 Mão Amiga

O **Mão Amiga** é um site desenvolvido como projeto acadêmico, com o objetivo de **conectar voluntários e instituições que precisam de ajuda**, promovendo solidariedade e apoio comunitário por meio da tecnologia.

---

## 🚀 Funcionalidades

- ✅ Página inicial com informações sobre o projeto  
- ✅ Formulário de contato e cadastro  
- ✅ Layout responsivo para dispositivos móveis  
- ✅ Navegação em página única (SPA)  
- ⚙️ Sistema de verificação de consistência em formulários  

---

## 🛠️Tecnologias Utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript (DOM e SPA)**
